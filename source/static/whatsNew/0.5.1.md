# Profile switching fix

- Profile selection keeps the Roku screen open instead of closing and recreating it.
- Playback reports drain before changing profiles; old tasks, timers, and user-scoped views are retired behind a request barrier.
- Requests and replies from an old scene or profile generation cannot use the next profile's session.
- Owner login stays saved; managed-profile tokens remain in memory and cannot fall back to owner history.

Physical Roku verification of the corrected profile-switching path is pending.
