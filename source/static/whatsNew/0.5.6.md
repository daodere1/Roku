# SpeshTV 0.5.6 — Viewing profiles

- Choose among up to three profiles at launch or use Switch profile from the account menu.
- Edit profile names and choose one of eight avatars; the profile-name keyboard initializes correctly, with clear save and cancel controls.
- Profile 1 retains existing viewing history. Additional profiles use separate Jellyfin identities with session-only credentials.
- Scope Continue Watching to the selected user, request fresh Resume data, and verify token identity with Users/Me.
- Drain playback reports before switching and isolate background tasks and per-user caches.
- Keep Home attached to the visible screen during profile changes.
- Retain local-first progress deduplication, season-first episode browsing, calendar freshness, guide filtering and existing playback fixes.

Viewing profiles require SpeshTV Core 3.1.0.9 or newer. Resume eligibility follows the server settings; this update does not change watch history or resume thresholds.
